## Fonctionnalités
- Carte interactive affichant les stations Vélib utilisées.
- Statistiques sur vos trajets.
- Graphique des utilisations au fil du temps.
- Filtrage par date et type de trajet.

## Installation
1. Installer les dépendances :
   ```bash
   npm install
   ```
2. Executer le setup initial :
   ```bash
   npm run setup
   ```
3. Génerer le bundle :
   ```bash
   npm run build
   ```
4. Le bundle est disponible dans le dossier `build/`.
